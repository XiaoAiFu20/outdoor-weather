# 徒步路线天气监测 · 操作指引 v0.2

> 把通用气象数据翻译成重装徒步可执行的决策。

---

## 一、5 分钟上手

1. 把 GPX 轨迹文件放到项目的 `gpx/` 目录（来自两步路、六只脚、Garmin 等均可，需包含轨迹点 + waypoint）
2. 启动服务：
   ```bash
   cd backend && python app.py
   ```
3. 浏览器打开 http://localhost:8000
4. 右上角选择 **出发日**，系统自动计算 D1-D4 行程风险
5. 点击地图上的 marker 或速览表中的行，查看该节点 7 天预报
6. 出发前点击右上角 **资源下载 → 离线包 PDF**，导出打印

## 三、数据源

| 数据源 | 默认 | 启用方式 | 强项 |
|---|---|---|---|
| **Open-Meteo** | ✅ 启用 | 默认 | 全球覆盖、含 DEM、网格 9km、免费无 key |
| **和风天气** | ❌ 未启用 | `export QWEATHER_API_KEY=xxx` | 国内合规、商业稳定 |
| **彩云天气** | ❌ 未启用 | `export CAIYUN_TOKEN=xxx` | 分钟级短临降水 |

申请地址：
- 和风天气：https://dev.qweather.com
- 彩云天气：https://dashboard.caiyunapp.com

### 多源融合算法
- **IQR 1.5 倍异常剔除**：剔除离群源
- **加权平均**：Open-Meteo 0.5 / 和风 0.3 / 彩云 0.2
- **WMO 雷暴优先**：任一家报雷暴 → 整体判雷暴
- 单源时自动退化（不影响功能）

## 四、海拔修正

气象 API 返回的是**网格点温度**（对应网格 DEM 海拔，可能与你的真实海拔差几百米）。本系统做两步修正：

1. **气温垂直递减率**：
   - 湿绝热 Γ = 6°C/km（默认，山区 RH ≥ 40%）
   - 干绝热 Γ = 9.8°C/km（RH < 40% 高寒垭口）
   - 公式：`T_real = T_grid - Γ × (h_real - h_grid) / 1000`

2. **风寒指数 WCT**（加拿大/中国气象局标准）：
   - 仅当 T < 10°C 且 V > 4.8 km/h 时启用
   - 公式：`WCT = 13.12 + 0.6215T - 11.37V^0.16 + 0.3965T·V^0.16`

## 五、降水相态

山区"山下下雨、山上下雪"是常态。本系统按海拔 + 温度判断：

| 条件 | 相态 |
|---|---|
| 海拔 > 3500m 且 T < 0°C | 雪/冰 |
| T > 3°C | 雨 |
| T < -1°C | 雪 |
| 中间区间 | 雨夹雪 |

## 六、风险徽章规则

### 🔴 失温（综合评分）
| 因子 | 加分 |
|---|---|
| 夜间体感 WCT < -5°C | +3 |
| 夜间体感 WCT < 0°C | +2 |
| 夜间体感 WCT < 5°C | +1 |
| 日降水 > 10mm | +2 |
| 日降水 > 3mm | +1 |
| 有雷暴 | +1 |
| 夜间最低温 < -2°C | +1 |

- **红警**：综合 ≥ 4
- **警惕**：综合 2-3
- **注意**：综合 ≤ 1

### ⚡ 雷暴
- **红警**：WMO ≥ 95（雷暴 / 雷暴+冰雹）
- **警惕**：WMO ≥ 80（阵雨）且降水概率 ≥ 70%
- **注意**：其他

### 🏔 高反（基于海拔）
- **红警**：海拔 ≥ 4000m
- **警惕**：海拔 ≥ 3500m
- **注意**：海拔 ≥ 3000m
- **低**：< 3000m

## 七、装备建议规则

基于全路线 7 天预报自动生成。规则示例：

| 触发条件 | 必带装备 |
|---|---|
| Tmin < -5°C | 羽绒睡袋 (comfort ≤ -15°C) |
| Tmin < 0°C | 羽绒睡袋 (comfort ≤ -10°C) |
| 有雷暴 | 急救毯 / GPS+离线地图 / 头灯 |
| 阵风 > 30 km/h | 防风冲锋衣裤 |
| 日降水 > 5mm | 防水内袋 |
| 海拔 ≥ 4000m | 氧气罐 + 红景天 |
| 相态含雪/冰 | 冰爪 + 雪套 |

完整规则见 `backend/pdf_export.py:recommend_gear()`。

## 八、改期建议

- 山区天气预报在 **5 天内** 准确度较高

## 十二、常见问题

**Q: 我的 GPX 没有 waypoint 怎么办？**
A: 系统会从轨迹点自动识别极值（垭口/谷底）作为关键节点，但精度不如人工标注。

**Q: 怎么让数据更准？**
A: 配置和风 + 彩云 key，三源融合会显著降低山区偏差。

**Q: 离线时还能用吗？**
A: 浏览器有缓存，但刷新页面会重新请求。建议出发前**导出 PDF 离线包**。

**Q: API 调用费用？**
A: Open-Meteo 完全免费。和风免费版 1000 次/天。彩云个人版免费。MVP 一条路线 26 个 POI × 每小时刷新 = 624 次/天，单源够用。
